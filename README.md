# R1_chassis

## 介绍
2026年xjrc电控组R1底盘代码,本赛季包含了许多更新，包括现在使用gitee进行代码管理、使用freertos进行了bsp、驱动、任务函数的解耦等操作。鄙人水平有限，
还需各位多多指正。

## 软件架构
软件架构说明
代码主要分为三大板块包括
BSP--硬件抽象层，包含对stm32的外设驱动
DRIVER--外设驱动层，包含对各个传感器、电机等外设的驱动
Task--应用层，包含各个功能模块的实现

### git使用要求
刚拿到仓库时若有任何不确定的地方可以先试着在readme最下面随便写点啥，确定功能没问题再进行正式开发。

每个拿到使用权限的成员都需要在仓库克隆下来之后在自己本地新建一个分支进行开发，此时可以正常通过gitee远程托管，写完后记得提交到远程仓库。

开发完成确保功能可以正常使用后，在gitee网站发起pull request请求合并到主分支，等待mhr审核通过后即可合并到master分支。

注意：不要直接在master分支上进行开发，以免引起冲突。

每次若有其他同学提交代码到master分支后，记得自己在本地先切换到master分支进行pull操作拉取最新代码，然后切换到自己的开发分支进行rebase操作，以确保自己的分支是基于最新的master分支进行开发，避免冲突。

每次发起pull request时请在下面写清楚更新内容，方便审核人员查看。
